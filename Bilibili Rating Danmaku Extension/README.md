# B站评分章节助手（Chrome 扩展 v1.1.0）

用于在你自己已登录的 Chrome 浏览器中，直接粘贴置顶评论时间轴，一键批量添加：
1. **五星评分弹幕**（`PlayerSetting` 弹幕配置编辑器，上限 12 字）
2. **视频章节导航条**（`ChapterSetting` 章节管理编辑器，上限 10 章 / 16 字）

## 安装与更新方法

1. 打开 Chrome 地址栏输入 `chrome://extensions/` 并回车。
2. 打开右上角 **「开发者模式」**。
3. 首次安装点击 **「加载未打包的扩展程序」**，选择本文件夹：
   `d:\Antigravity文件下载位置\写插件\Bilibili Rating Danmaku Extension`
4. 后续有代码更新时，只需在扩展卡片右上角点击 **刷新按钮 `↻`** 即可。

## 使用方法

1. 在视频播放页点开扩展，可直接点击顶部的 **「打开评分编辑器」** 或 **「打开章节编辑器」** 跳转对应界面。
2. 粘贴置顶评论时间轴（支持单行或歌名时间分两行），选择统一 **中文** 或 **英文**，支持一键在两个标签页间同步歌单。
3. 在预览框微调确认后，点击 **「一键批量添加评分」** 或 **「一键填入导航条」** 即可自动完成并保存。
